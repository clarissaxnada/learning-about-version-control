## About Version Control:

1. Benefit: Version control keeps a full history of past changes, so the team can look back at what worked and what did not and make concrete improvements in later versions.
2. Challenge: When team members forget to pull the latest updates before they start working, their changes can conflict with everyone else's, and sorting that out gets confusing.
